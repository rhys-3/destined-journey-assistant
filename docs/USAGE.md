# 使用说明

预设提供「表达设置」板块时，「表达约束」显示为总开关，下方统一排列该板块中的可选细则，包括自建条目。关闭总开关会禁用子控件并保留勾选状态，重新开启后恢复使用。从该板块新增条目时，发送位置默认在表达约束条目前，界面则显示在子选项末尾。条目正文保持原样；自定义规则是否随总开关注入，仍由条目的宏写入与表达约束条目中的读取关系控制。

## 预设设置

从悬浮球、输入框上方“命定预设助手”按钮或魔术棒菜单进入。显示设置可独立控制三个入口，至少保留一个。四套主题和透明度适用于整个助手，桌面支持拖动缩放，手机自动适配。

面板依次提供日常调整、自定义设定、文风与表达、模型与工具、总结设置和设置。设置页包含配置管理、界面外观和打开方式，顶部配置管理快捷入口跳转到该页。条目列表从面板顶部进入。编辑模式开启后可新增、编辑、删除预设条目，关闭面板会退出编辑模式。条目用稳定 ID 与原生界面双向同步，检测到并发变化会停止覆盖；排序支持桌面拖动和触屏操作，筛选期间需恢复完整列表。

“自定义设定”包含全局设定和用户附加设定。全局设定用于填写持续生效的设定，可覆盖其它世界设定与角色设定；用户附加设定用于补充对用户角色的描述要求。点击“＋ 添加”直接出现输入框，每条可独立启用、上下移动或删除，并可撤销最近一次删除，无需开启编辑模式。内容自动保存，下次生成时按顺序以 `- ` 列表发送；空白和停用项不发送，多行内容仍属于同一条。

两种设定各有总开关，关闭时仍可编辑且保留逐条选择。“恢复默认”仅恢复用户附加设定的三条默认内容、顺序与逐条开关，不改变总开关。错误文本或保存失败的草稿会保留并提示，修正后可再次保存。

“文风与表达”中的“NSFW内容”集中显示通用、男性向、女性向和防发情模式，选择一种后自动保存。下方 SFW 描写、亲密节奏和描写约束独立启停，切换模式会保留这些选择；收起区域后仍能看到当前模式与已开启的附加项数量。手机上模式卡片按两列排列，附加项逐行显示。具体行为取决于对应条目的正文，界面简介可在编辑模式中修改。

NSFW 板块起始和结束条目作为必需结构保留，可在条目列表阅读或编辑正文，不能在助手中停用或删除。旧版预设只显示实际存在的模式，不自动创建新提示词；原生列表出现多个模式同时启用时，界面会提示重新选择。若用户将附加描写移动至其他页面或隐藏，助手遵循该布局，不强制合并显示。

新建条目未修改时可以直接关闭，板块自动填写的位置也不算修改。保存成功后编辑窗自动关闭，失败时保留草稿。删除、覆盖配置和重命名等确认或输入使用助手自己的主题弹窗。

新建条目可以选择「独立开关」或「单选项」。从单选板块新增时默认单选，从其他板块新增时默认独立开关；手动选定类型后再更换普通板块，会保留所选类型。单选项加入所选板块的单选组，只与该组单选项互斥，不影响独立开关。新增未启用的单选项会保留已有选择；若组内尚无选中项，则自动选中第一项。保存后，移动条目仍保留原单选关系。

基调和主文风继续使用板块上的专用新增入口，自动补齐各自提示词格式并沿用原有互斥逻辑。普通条目编辑器不会把新条目直接加入这两组，但可在它们的板块添加独立开关。已有基调、主文风和模型联动关系不因新建控件类型而改变。

条目编辑器在名称下方提供「界面简介」，支持普通开关、单选项和新建条目。对白条目分别编辑对白比例、最低对白轮次的简介；输出条目分别编辑正文语言、思维链语言、正文字数和单次战斗回合的简介。输入时显示预览，建议写一两句话，每段最多 2000 字；清空并保存后不显示简介。长文案自动换行，换行与纯文本原样显示，不解析 HTML 或宏。

简介只用于助手界面，随条目复制、移动、预设保存和预设配置导出保留，不加入提示词正文。旧预设自动沿用原有简介或默认说明；只改正文不会覆盖外部更新的简介。「可选细则」标题、总开关的状态说明，以及模型和变量模式专用控件的运行提示由界面管理，不属于条目简介。

模型连接联动使用酒馆 Connection Profile，连接自身的凭据由酒馆管理。变量模式联动世界书的已有条目，缺失、冲突或保存失败会提示并可重试。MVU 更新方式和世界书事件链需要按所用世界书的说明配置。

## 总结：记录、任务与提示词

总结保留三种生成方式：“自动总结”开关按阈值处理，“手动开始总结”立即处理当前可总结的一轮，“指定楼层总结”自行输入起止楼层。三种方式均按每批上限拆分普通总结请求。关闭自动总结仍可使用后两种方式。大总结也支持自动合并和手动选择普通总结后合并。

自动总结默认关闭。批次方案可手选“已开启摘要”推荐的 50 楼触发、保留 10 楼，“未开启摘要”推荐的 20 楼触发、保留 5 楼，或自定义。默认保留原有自定义的 30/10/20 参数；不读取摘要状态。每批上限独立控制单次材料量，默认逐批生成并保存，可勾选并发并设置数量。大总结默认累计 15 条普通总结后合并最早连续的 10 条。用户输入与 AI 正文分别记录，只有结果可靠保存后才隐藏原文。

顶部提示、面板与入口共用任务状态。关闭提示或面板不停止任务；“停止本次任务”与“暂停自动总结”分别控制当前请求和后续队列。保存或显隐失败可只重试对应阶段，编辑提示词与连接参数在下次任务生效。

总结页分为记录与任务、生成设置、提示词、世界书，保存反馈位于助手左下角。提示词支持编辑、改名、角色、排序、宏、展开预览和专用导入导出；普通与大总结各使用可拖动的条目列表，右侧开关启停，点击名称弹窗编辑；输出格式、检查与尾部预填充均为可选条目。记录与任务前部提供楼层显隐统计、范围和类型控制；楼层明细展开后每页最多显示 30 楼，支持筛选和按编号跳转，点击查看才读取该段原文。任务显示日志与各批进度。第 0 楼正常计数，指定楼层使用两个数字输入框。默认采用时间地点档案，格式选择同时改变发送规则与返回校验。新结果统一使用 `<summary_result>` 标签，标签外内容不保存。主连接和自定义 API 支持温度及最大 Tokens 的跟随或覆盖，自定义 API 可获取或手填模型。

完整操作、恢复规则、世界书边界及真实环境实测清单见 [后台总结说明](SUMMARY.md)。

## 配置管理

保存命名配置时勾选“预设配置”“总结配置”，默认全选，至少选一项。覆盖与另存为按所选范围捕获；切换、脏状态判断、恢复点只影响所含部分。

导出单份或配置库前可再次选择范围。没有所选部分的项目跳过，全部为空时提示。分享格式标识仍是 destined-configurations，外层版本 2，快照含可选 preset、summary。旧版 version 1 按仅预设配置导入；仅总结配置无需完整预设条目。

导入保留结构校验与重名处理，成功后不自动应用。写入失败回滚并显示结果。配置库损坏时仅能导出仍可校验的配置，原始变量继续保留。

配置不包含 API Key、世界书、绑定、聊天／总结记录、隐藏楼层。预设部分保留提示词正文、生成参数与助手识别的显示元数据，不复制未知第三方扩展数据。用户主动写在提示词正文中的敏感文本无法自动辨别，分享前需检查正文。
