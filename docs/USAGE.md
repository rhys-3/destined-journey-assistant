# 使用说明

## 预设设置

从悬浮球、输入框上方“命定预设设置”按钮或魔术棒菜单进入。显示设置可独立控制三个入口，至少保留一个。四套主题和透明度适用于整个助手，桌面支持拖动缩放，手机自动适配。

面板提供日常调整、文风与偏好、模型与工具、条目列表和配置管理。编辑模式开启后可新增、编辑、删除条目，关闭面板会退出编辑模式。条目用稳定 ID 与原生界面双向同步，检测到并发变化会停止覆盖；排序支持桌面拖动和触屏操作，筛选期间需恢复完整列表。

模型连接联动使用酒馆 Connection Profile，连接自身的凭据由酒馆管理。变量模式联动世界书的已有条目，缺失、冲突或保存失败会提示并可重试。MVU 更新方式和世界书事件链需要按所用世界书的说明配置。

## 总结：记录

打开独立启用开关，再绑定当前聊天的总结世界书。支持新建、绑定、迁移、解绑；迁移包含普通和大总结，保留无关条目。绑定记在聊天变量中，通过调整全局启用世界书列表使当前绑定生效。共享世界书的聊天会共享对该书的修改。

默认每累计 30 条未总结的原始消息楼层触发，保留最新 10 条。例如尚无总结，已有 0—29 楼时总结 0—19 楼。按原始楼层计数，不是只数助手回复；正文另按标签过滤。默认自动触发不事前确认，结果仍进入审查。可开启自动触发确认，或手动、指定楼层生成。

生成期间重复操作会被阻止。结果可编辑保存或取消；失败可重试或手工填写保存。切换聊天、预设或关闭总结时会取消旧请求，迟到结果不会继续保存。请求等待上限为 5 分钟。

普通条目名沿用“总结0-19楼”，大总结沿用“大总结0-99楼”。均支持编辑、重生成、删除和启停。大总结合并保留原普通条目并禁用；还原恢复来源普通条目。有效大总结覆盖的普通条目不能单独启用，避免重复注入。

自动显隐只恢复助手自己隐藏的楼层，不打开用户原先手动隐藏的楼层。关闭总结不会删除记录、解绑世界书或自动恢复已隐藏楼层，需在记录和参数中处理。

## 总结：参数与提示词

可设置触发／保留楼层、标签、前缀、旧总结引用、自动隐藏、主／自定义 API、温度和最大 Tokens。温度与 Tokens 支持跟随预设。自定义接口需填写地址和模型，模型列表通过酒馆助手获取。

API Key 存在当前设置脚本的独立变量中，按接口地址区分；切换地址不会携带旧地址密钥。这不是系统加密保险库。命名配置、恢复点和导出都不包含 Key。

普通总结和大总结各有提示词板块，支持增删、编辑、启停、排序；动态板块插入旧总结、聊天或选中的总结。默认板块来自当前预设元数据。表单自动保存，页面切换保留草稿，存储失败显示失败。

## 配置管理

保存命名配置时勾选“预设配置”“总结配置”，默认全选，至少选一项。覆盖与另存为按所选范围捕获；切换、脏状态判断、恢复点只影响所含部分。

导出单份或配置库前可再次选择范围。没有所选部分的项目跳过，全部为空时提示。分享格式标识仍是 destined-configurations，外层版本 2，快照含可选 preset、summary。旧版 version 1 按仅预设配置导入；仅总结配置无需完整预设条目。

导入保留结构校验与重名处理，成功后不自动应用。写入失败回滚并显示结果。配置库损坏时仅能导出仍可校验的配置，原始变量继续保留。

配置不包含 API Key、世界书、绑定、聊天／总结记录、隐藏楼层。预设部分保留提示词正文、生成参数与助手识别的显示元数据，不复制未知第三方扩展数据。用户主动写在提示词正文中的敏感文本无法自动辨别，分享前需检查正文。
