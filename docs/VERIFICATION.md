# 验证记录

## 自动验证

- 范围边界、标签、两类 API、scan-only、防合并标记、深度 9998／9999、合并还原、世界书迁移、楼层显隐。

- 旧 v2.8.3 文件哈希不变、固定版本加载器。
- 原设置浏览器回归：双向同步、模型连接、世界书联动、编辑排序、配置恢复、入口、布局与生命周期。
- 合并回归：总结页、自动保存、提示词增删、草稿、配置范围、v1 导入、手动总结审查保存、无独立旧窗口。
- 四套主题桌面／手机；总结三子页在 1280、390、320 宽检查溢出。

浏览器测试使用隔离 Chrome 和模拟酒馆 API，不向真实模型发请求。结果与截图在 .ui-review/ 或 Actions verification artifact。Actions 使用 Node 22／pnpm 10 冻结安装，测试后构建并检查提交产物一致。

## 发布检查

scripts/check-legacy-links.mjs 检查旧地址 v2.7.0、v2.8.2、v2.8.3、main、latest、无版本文件的 HTTP 与规范化 SHA-256，改名前后及发布后执行。

新版固定 CDN 内容需与 dist 一致，之后才同步正式 split。预设工作区依规定执行 lint → build → 最终 JSON lint，检查入口唯一、UUID 不变、无 Key，source 不修改。网络与打包结果以本次发布记录和检查输出为准。

## 真实环境未完成

真实 SillyTavern 的模型生成、网络权限、连接与世界书事件时序、快速切换聊天的宿主写入行为、手机触屏实机体验均**未标记通过**。模拟通过不替代真实环境验证。建议在备份聊天中先用少量指定楼层检查审查保存，再验证自动触发、大总结合并还原与聊天切换。
